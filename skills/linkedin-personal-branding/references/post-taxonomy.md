# Post Taxonomy

Use these stable archetypes instead of imitating noisy labels literally. Every
authored post — observed or generated — is classified with exactly one
archetype, one primary goal, and one CTA type from the lists below. Use only
these labels.

## Archetypes

- `tactical_blueprint`
  - step-by-step methods and operating playbooks
- `contrarian_pov`
  - myth-busting, category attacks, reframes
- `results_case_study`
  - before/after proof and quantified outcomes
- `diagnostic_framework`
  - self-assessment, options, strategic lenses
- `resource_guide`
  - curated tools, guides, grouped resources
- `audience_activation`
  - comment harvesting, community prompts, qualification
- `founder_story`
  - personal credibility and lived lessons
- `feature_announcement`
  - product updates framed by workflow value
- `community_milestone`
  - community growth, gratitude, soft proof

## Noisy Name Collapse

When observed content resembles branded or noisy formats, collapse to the
stable archetype:

- `Solutions Guide`, `Essential Solutions Guide`, `Essential Guide Simplified`
  - use `resource_guide`
- `Opportunity Spotlight Network`
  - use `audience_activation`
- `Strategic Approach Options`, `Evolution of Approaches`, `Strategy Implementation Framework`
  - use `diagnostic_framework`
- `Proven Results Framework`, `Results-Driven Success Formula`
  - use `results_case_study`

## CTA Types

- `comment_keyword`
- `comment_prompt`
- `dm_me`
- `visit_link`
- `follow_for_more`
- `repost`
- `soft_reflection`

Use `soft_reflection` when there is no strong explicit CTA.

## Primary Goals

- `awareness`
- `category_education`
- `authority`
- `proof`
- `engagement`
- `lead_gen`
- `product_education`
- `conversion`

## Interpretation Rules

- Treat `founder_story` as the personal bucket.
- Treat `audience_activation` as the community prompt / comment harvest bucket.
- Treat explicit conversion or offer capture posts as sales-forward even when
  they also educate.
- Treat these CTA types as on-platform conversion when the ask stays inside
  LinkedIn: `comment_keyword`, `comment_prompt`, `dm_me`.
- Base percentage distributions on authored posts only, not comments.
- When judging sales pressure, distinguish value-first educational posts from
  posts whose main point is conversion, offer capture, or product promotion.
